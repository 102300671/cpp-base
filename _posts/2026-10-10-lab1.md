## work1 · 三个数排序（指针与引用）

**练习要点**：用指针参数和引用参数各实现一个交换函数，通过函数重载让两者同名；程序运行时由用户选择采用指针（输入 `1`）还是引用（其他输入）方式，把三个整数按从小到大排序输出。

**设计思路**：定义两个重载的 `swap_if_greater`：

- 指针版本 `swap_if_greater(int*, int*)`：解引用后比较交换；
- 引用版本 `swap_if_greater(int&, int&)`：直接对实参操作。

排序采用「冒泡式」的 3 次比较交换：先让前两个有序，再处理后两个，最后再校正前两个，即可保证三数升序。

{% include_source cpp-src/lab1/work1/sort_three.cpp %}

**运行示例**：

```console
$ echo "3 1 2 1" | ./sort_three
请选择方法（1: 指针，其他: 引用）：1 2 3
$ echo "3 1 2 0" | ./sort_three
请选择方法（1: 指针，其他: 引用）：1 2 3
```

指针与引用两种方式结果一致；区别在于指针版本需要取地址并解引用，引用版本在语法上更接近普通变量，且调用时无需 `&`。

**使用引用时要注意的问题**：

- **必须初始化、不能为空**：引用在定义时必须绑定到一个已存在的对象，不存在"空引用"，也不能先声明后绑定；
- **不能重新绑定**：引用一旦绑定某个对象，就一直是它的别名，不能像指针那样改指向别的对象；
- **实参必须是可修改的左值**：非常量引用 `int&` 不能绑定字面量或右值（如 `swap_if_greater(1, 2)` 会编译失败）；若函数不打算修改实参，应改用 `const int&`；
- **会直接修改实参**：函数内对引用形参的读写就是对实参本身的读写，调用方无感——本练习的排序正是利用这一点；若不想改动实参，应传值或 `const` 引用；
- **与指针可重载共存**：`swap_if_greater(int*, int*)` 与 `swap_if_greater(int&, int&)` 签名不同，故能通过函数重载并存，由实参类型自动选择版本。

## work2 · 两 / 三数最大值（重载与默认参数）

**练习要点**：实现求两个数、三个数最大值的函数，对比**函数重载**与**默认参数**两种写法；程序先输入个数（`choice`：2 或 3），再选择使用哪个版本（`option`：非 0 为重载版本，0 为带默认参数版本）。

**设计思路**：

- 重载版本：`max_overload(int, int)` 与 `max_overload(int, int, int)` 是两个独立函数，靠参数个数区分；
- 默认参数版本：`max_default(int a, int b, int c = 0)` 只写一个函数，第三个参数默认取 `0`——求两个数时 `c` 为 0 不影响最大值，求三个数时传入实际值。

{% include_source cpp-src/lab1/work2/max_of.cpp %}

**运行示例**：

```console
$ printf "2 1\n5 8\n" | ./max_of
输入 choice(2或3) option(0=带默认参版本，非0=重载版本): 
8
$ printf "3 0\n7 2 9\n" | ./max_of
输入 choice(2或3) option(0=带默认参版本，非0=重载版本): 
9
```

## work3 · 字符串排序（指针数组）

**练习要点**：输入 5 个字符串，存入 `string*` 指针数组（每个元素动态 `new`），用选择排序按字典序输出，最后 `delete` 释放并置空指针。

**设计思路**：

- `string* arry[5]` 是元素为 `string*` 的数组，`new string` 在堆上为每个字符串分配空间；
- 选择排序每一轮找剩余元素中字典序最小的下标 `m`，`arry[m]->compare(*arry[j]) > 0` 表示当前元素字典序更大；
- 排序后 `swap(arry[i], arry[m])` 只交换指针本身，不移动字符串内容；最后逐个 `delete` 并置 `nullptr`，避免悬空指针。

{% include_source cpp-src/lab1/work3/string_sort.cpp %}

**运行示例**：

```console
$ printf "pear\napple\norange\nbanana\ngrape\n" | ./string_sort
apple
banana
grape
orange
pear
```

## work4 · 数组排序（函数重载）

**练习要点**：对 `int`、`float`、`double` 三种类型的数组分别实现选择排序 `csort`，用**函数重载**让三个版本同名；程序按用户选择的类型（0：整型，1：单精度，其他：双精度）动态分配数组并排序输出。

**设计思路**：

- 三个 `csort` 函数体完全一样（选择排序），仅数组参数类型不同，编译器根据实参类型自动选择对应版本；
- 数组用 `new[]` 动态分配，用后 `delete[]`；
- 缺点：同一种算法要为每种类型重复写一遍代码。

{% include_source cpp-src/lab1/work4/t_sort.cpp %}

**运行示例**：

```console
$ printf "0\n5\n3 1 4 1 5\n" | ./t_sort
0:整型;1:单精度;其它:双精度
个数:1 1 3 4 5 
$ printf "1\n3\n2.5 1.2 3.8\n" | ./t_sort
0:整型;1:单精度;其它:双精度
个数:1.2 2.5 3.8
```

## work5 · 数组排序（函数模板）

**练习要点**：实现与 work4 相同的功能，但改用**函数模板**：`init<T>` 读入、`csort<T>` 排序、`print<T>` 输出、`destroy<T>` 释放，一套代码支持所有类型。

**设计思路**：

- `template <typename T>` 让函数与具体类型解耦，调用时显式指定 `init<int>(n)` / `init<float>(n)` / `init<double>(n)`，编译器按需实例化；
- 与 work4 的重载版本相比，消除了重复代码，新增类型（如 `long`）无需再写一套函数；
- `swap(array[m], array[i])` 依赖 `<utility>` 中的标准 `swap` 模板。

**运行示例**：

## 总结

- **指针 vs 引用**（work1）：两者都能在函数内修改实参；指针需显式取址/解引用，引用更直观且调用方无感，但引用必须在定义时绑定、不能为空。
- **重载 vs 默认参数**（work2）：重载靠参数个数/类型区分，灵活但代码多；默认参数用一个函数覆盖多种调用，简洁但语义不如重载明确。
- **重载 vs 模板**（work4/work5）：重载对每种类型写一份实现，类型多时代码膨胀；模板一份代码自动实例化，是消除重复的更优方案。
- **动态内存**（work3/work4/work5）：`new`/`delete` 与 `new[]`/`delete[]` 必须配对，释放后将指针置空是良好的防御习惯。
